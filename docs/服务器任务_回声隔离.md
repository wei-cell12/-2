# 服务器任务：回声隔离（用熵差找出复述里抄来的用户答案，读图阶段让模型读不到它），ClockQA 20 题

**做什么**：生成新回答（ClockQA）。

1. **熵差分支**：生成时同步跑一条分支，提示里的问题换成模型自己改写的中性问题（仓库里已有：Qwen 用 `results/compare_cq_20261029/a100/neutralized/`，Gemma 用 `results/gemma4_cq_20261029/neutralized/`），思考与主回答相同，只读不写。每一步算熵差 ΔH。
2. **回声**：从思考开头到读图窗口结束，每段连续负熵差里只要有一步 ≤ −1，这一段的词就算回声，也就是从用户那里抄来的答案，例如 "12:35:00 is correct."。
3. **echo 组**：开头一段写完后的 128 个词里，每个标准注意力层（Gemma 包括滑动窗口层）里，当前词对回声位置的注意力权重乘以 0，不重新归一化。这样注意力分布不变，只是读不到回声的内容。128 个词之后照常生成，熵差分支也停掉。
4. **base 组**：熵差分支同样跑、回声同样记录，不改。

两组用同一个随机种子（42）。

**题目**：与 `fp-maskq` 相同的 ClockQA 选题（每个模型 20 题），用户说错、说对都做。每个模型 20 × 2 × 2 = 80 次生成。

**预计耗时**：熵差分支只在开头和读图窗口里跑，每个模型一个进程约 3–4 小时；可以用 `--shard k/n` 分多份并行。

## 规则

- 不要修改任何代码、参数、阈值或清单，也不要额外运行检查命令（下面列出的命令除外）。运行前确认 `git status` 干净。
- 用之前熵谷注入、锚点一、fp-maskq 跑通时的同一个 Python 环境（51 上是 `conda activate gemma4`），不要安装或升级任何库。
- 报错就停下汇报错误信息；不要自己打补丁，不要自动重试。
- 停进程用 `kill -TERM`，不要用 Ctrl-C；不要停止或抢占别人的进程。只用我指定的服务器和卡。
- 全部在标注用的那份仓库里做。不要上传 npz。
- 不要碰 50 上卡住的 GPU4、GPU6 和那个挂起的进程。

## 命令

用和 fp-maskq 相同的本地化配置、熵差目录和图像目录。`<仓库>` 指这份代码目录的绝对路径。

```bash
cd <仓库> && git pull && git status
python -m pytest tests/test_fp.py -q -rs        # 应全部通过，没有 skipped
EQ=<结果目录>/echo-qwen38-20261108
EG=<结果目录>/echo-gemma4-20261108
mkdir -p $EQ $EG
# 每份一组卡；n 份时第 k 份（k = 0 … n−1）
CUDA_VISIBLE_DEVICES=<卡> nohup python run.py fp-echo --phase run --config <Qwen 本地化配置> --root $EQ --entropy-dir <Qwen 本地化熵差目录> --model-key qwen38 --neutral-dir <仓库>/results/compare_cq_20261029/a100/neutralized --image-dirs <图像目录> --shard k/n > $EQ/run_k.log 2>&1 &
CUDA_VISIBLE_DEVICES=<卡> nohup python run.py fp-echo --phase run --config <Gemma 本地化配置> --root $EG --entropy-dir <Gemma 本地化熵差目录> --model-key gemma4 --neutral-dir <仓库>/results/gemma4_cq_20261029/neutralized --image-dirs <图像目录> --shard k/n > $EG/run_k.log 2>&1 &
# 全部完成后（--maskq-root 指向 fp-maskq 的结果目录，一起对比；Gemma 的 fp-maskq 没跑完就先不加这个参数）
python run.py fp-echo --phase summary --root $EQ --label "Qwen3.8-27B · ClockQA" --maskq-root <仓库>/results/maskq_20261108/qwen38
python run.py fp-echo --phase summary --root $EG --label "Gemma 4 31B-it · ClockQA" --maskq-root <仓库>/results/maskq_20261108/gemma4
```

中途断了用同一条命令重跑，已完成的会自动跳过。
