# 服务器任务：锚点一试跑，读图阶段把看图注意力往参照分支拉（ClockQA 4 题）

**做什么**：生成新回答。生成时同步跑一条参照分支：
- 提示去掉用户那句话；
- 思考里删掉开头的复述段（思考开头到第一个空行）。

在复述段之后的 128 个 token 里，每一步按参照分支调整主回答的看图注意力：
- 看图总量只补不压；
- 图像内部分配向参照靠一半。

每题、每种条件生成两遍，用同一个随机种子：
- base：参照分支照跑，但不改主回答；
- pull：按参照改。

两遍在窗口开始前应逐 token 相同。

**题目**：CQ-003、CQ-022、CQ-037（被带偏）和 CQ-009（守住）。每题有用户说错、用户说对两条，每个模型共 16 次生成。

**预计耗时**：每次生成最多约 4600 个 token，每个模型约 1 小时。

## 规则

- 不要修改任何代码、参数、阈值或清单，也不要额外运行检查命令（下面列出的命令除外）。
- 报错就停下汇报错误信息；不要自己打补丁，不要自动重试。特别是"参照分支逐步计算与整段计算不一致"这类报错，原样汇报。
- 停进程用 `kill -TERM`，不要用 Ctrl-C；不要停止或抢占别人的进程。
- 全部在标注用的那份仓库里做。不要上传 npz。
- 不要碰 50 上卡住的 GPU4、GPU6 和那个挂起的进程。
- 判读时不告诉判读者模型名、条件或正确答案。本任务的判读是自动的，不需要人工判读。
