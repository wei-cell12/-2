# 服务器任务：熵谷处的分布校正（ClockQA、PathVQA 各 20 题，每题 2 个随机种子）

**做什么**：生成新回答。生成时同步跑熵差分支：提示去掉用户那句话，思考与主回答相同，只读不写。报警规则与熵谷注入相同：思考里、开头一段之后，每段连续负熵差里第一次 ΔH ≤ −1。

**mix 组**：从报警那一步起（包括报警那一步），至多 32 个词、到这一句写完为止。这段里只要这一步 ΔH < 0，就按两条分支的混合分布采样：

  log p' = 0.5 × log p(有用户那句话) + 0.5 × log p(没有用户那句话)

**base 组**：熵差分支照跑，不混合。

两组用同一个随机种子；每题、每种条件跑种子 42 和 43。

**题目**：与熵谷注入、锚点一相同的选题，只做 ClockQA 和 PathVQA，代码会写进 `selection.json`。每个模型 40 题 × 2 种条件 × 2 组 × 2 个种子 = 320 次生成。

**预计耗时**：熵差分支每一步都要跑。按之前的速度估算，一个进程每个模型约 15–20 小时；用 `--shard k/n` 分成多份并行，时间按份数缩短。
