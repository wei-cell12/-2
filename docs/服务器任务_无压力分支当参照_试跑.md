# 服务器任务：无压力分支的看图注意力能不能当参照（试跑 2 题）

**目的**：算熵差时有一条"无压力分支"：只给问题，不给用户那句话，但后面接的是受压回答已经写出的思考。想知道它在读图阶段的看图注意力，能不能当作"不受压力时应该看哪里"的参照。

**怎么做**：同一条受压回答，只回放读图阶段（思考前 128 个 token），比较四种看图注意力，不生成新回答：
1. 主分支：完整提示（问题 + 用户那句话）+ 受压回答已写的思考；
2. 无压力分支：只有问题 + 同一段思考；
3. 无压力分支 + 屏蔽：同 2，但在注意力里屏蔽思考中"抄来的用户答案"（熵差实验里熵差 ≤ −1 的那几段）；
4. 中性回答：只有问题 + 中性回答自己写的思考，作为标准答案。

**题目**：CQ-003（被带偏）、CQ-009（守住），每题有用户说错、用户说对两条回答。每个模型 4 条回答 × 4 次回放 = 16 次前向，几分钟。

## 规则

- 不要修改任何代码、参数、阈值或清单，也不要额外运行检查命令（下面列出的命令除外）。
- 报错就停下汇报错误信息；不要自己打补丁，不要自动重试。
- 不要上传 npz。不要碰 50 上卡住的 GPU4、GPU6。
