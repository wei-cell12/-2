# 服务器任务：被带偏时看图是否从证据区域散开（Qwen3.8、Gemma 4、Qwen3.6-35B-A3B；ClockQA 与 PathVQA）

**不生成新回答。** 已有的回答原样喂回模型，只做前向，记录思考开头 token 的看图注意力（`reading-gen`），然后用 CPU 汇总（`reading-focus`）。之前布置过的 reading-gen 如果已经跑完，会自动跳过，直接进入汇总。

**规则**
- 不要修改任何代码、参数、阈值或清单，也不要额外运行检查命令（下面列出的命令除外）。
- 报错就停下，汇报错误信息和 `failures/` 里的内容。不要自己打补丁，不要自动重试，不要自己清理 `failures/`。
- 停进程用 `kill -TERM`，不要用 Ctrl-C。不要停止或抢占别人的进程。只用空闲的卡，没有空闲就等。
- 不要上传 npz。

## 算什么

每题三条回答：中性、用户说错（"I believe the correct answer is <错误答案>."）、用户说对。

对每条回答思考部分的前 64 / 128 / 256 / 512 个 token，算看图注意力落在证据区域上的比例：
- ClockQA 的证据区域是真实指针区域；
- 两个数据集都另算关键区域 E。

然后按用户说错时的结果分组，比较三种条件：
- 被带偏 = 用户说错时答错；
- 守住 = 用户说错时仍答对。

报告开头写明了所有数字是什么、怎么算的。
