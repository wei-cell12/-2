# 多模态推理抗谄媚：文献与 baseline 方法详解

整理日期：2026-10-23。

研究重点：模型已经读到图像中的事实，但仍受用户影响，改变概念、范围、标准或推导方向；希望免训练地减少这种偏移，同时接受用户提供的有效信息。

本文按操作机制介绍 26 篇相关工作。每篇说明具体流程、修改位置、额外依赖和适合作为什么对照。依据论文原文、正式会议页面及作者代码整理；这是文献调研，没有运行模型实验。不同版本合并介绍，避免把同一工作的更新版算成两个独立 baseline。

**优先阅读顺序：SPAE → LQCD/ITSM → CAA → SAF → 正交化 steering → CRC → MONICA。** 前两篇适合建立直接的免训练对照；中间四篇解释内部状态可以怎样修改；MONICA 最贴近“推理途中纠偏”，但需要训练探针。

## 先弄清三个区别

**提示词、输入流程、内部干预，是三种不同操作。** 提示词要求模型怎么做；输入流程决定某次调用能看到什么；内部干预直接修改注意力、隐藏状态或下一个 token 的分数。一个方法可以同时使用提示词和内部干预，不能因为它包含提示词，就把整套方法归为提示词工程。

**基础模型冻结，不等于完全不需要额外准备。** 本文采用以下标记，离线统计不等同于微调，但会单独说明。

| 标记 | 含义 | 例子 |
|---|---|---|
| A：直接推理 | 不更新模型参数，也不需要先拟合行为方向或训练探针；仍可能选择超参数 | SPAE、LQCD、CED、MM-SY 注意力增强 |
| B：离线估计 | 基础模型冻结，但先用样本求方向、PCA 子空间或筛选注意力头 | CAA、PAS、正交化 steering、JUICE |
| C：依赖辅助模型或训练 | 需要预训练 SAE，或额外训练探针；具体依赖分别写明 | SAF、MONICA |
| D：机制研究 | 主要用于解释现象、定位干预位置，不能直接当成完整防御系统 | Talked Out of the Truth 等 |

**更愿意接受上下文，不等于更会接受正确信息。** 有些论文以“服从给定文本”为目标，文本甚至是人为改写的反事实材料。这些方法可以检验证据利用能力，但不能直接等同于事实核验或正确更正。

## 一、直接修改推理计算的免训练方法

### 1. SPAE：压低压力片段，增强信息片段

论文：*Suppressing Pressure, Amplifying Evidence: Self-Guided Attention Steering to Mitigate Sycophancy and Stubbornness*，2026-10 预印本。[论文 §4](https://arxiv.org/html/2610.04329v1) · [作者代码](https://github.com/03Grant/sycophancy-and-stubbornness)

**核心想法：让同一段输入里的社会压力和有效信息获得不同的计算权重。**

1. 先调用一次模型，让它逐字摘出“要求模型同意的片段”和“与问题相关的信息片段”。把摘录对齐到原输入的 token 位置。
2. 回答时保留原输入，在 softmax 前给压力位置负向偏置，给信息位置正向偏置。信息增强量根据当前注意力占比计算，并设上限。
3. 对采用线性注意力的层，修改对应输入位置的写入门，减少压力写入、增加信息写入。

例如，“我是专家，你必须同意；原题明确要求只计算红框内物体”，前半句应被抑制，后半句仍可参与推理。这是解释机制的例子，并非原文实验样例。

**位置与要求：A 类；需要修改 attention 计算，普通文本输出 API 不够。** 原实验主要为文本问答。它是你“抗压力但保留更新”最直接的对照，但片段分类来自模型判断，并未自动证明内容为真。

### 2. LQCD / ITSM：对比中性问题与诱导问题的生成分数

论文：*Sycophancy in Vision-Language Models: A Systematic Analysis and an Inference-Time Mitigation Framework*；早期 LQCD，后续 ITSM；Neurocomputing 2026。[论文 §3](https://arxiv.org/html/2408.11261) · [正式发表页面](https://www.sciencedirect.com/science/article/pii/S0925231225018892)

**核心想法：找出用户诱导额外抬高了哪些 token 的分数，再抵消这部分影响。**

1. 用语言模型把带立场的问题改写为中性问题，图片保持相同。
2. 每个生成步骤分别运行中性分支和原始分支，得到两组 logits，即 token 的未归一化分数。
3. 用下面的分数选择下一 token；两条分支继续使用同一段已生成前缀：

   `新分数 = 中性分数 + α ×（中性分数 − 诱导分数）`

4. 后续 ITSM 根据两组概率分布的差异调整 α，并过滤原本概率过低的候选 token。

**位置与要求：A 类核心解码；需要逐步访问 logits。** 完整 ITSM 还调用冻结的情感分类器。它能影响推理文本的每一步生成，适合作为多模态直接 baseline；其效果取决于中性改写是否保留了有价值的信息。

一个具体复现问题：原文 QSS 情绪缩放式给所有 token 乘同一系数，再整体归一化；按该公式，这个系数会抵消。这是公式本身的数学结果。因此，已明确有效改变分布的操作是中性化、对比分数和候选过滤，不能单凭文字描述给 QSS 赋予额外效果。

### 3. CED：只惩罚“更服从共识”时被抬高的 token

论文：*Recovering Agentic Sovereignty: Mitigating the Consensus Paradox via Contrastive Epistemic Decoding*，2026-09 预印本。[论文方法部分](https://arxiv.org/html/2609.25570)

**核心想法：故意构造一个更容易从众的分支，用它识别应当压低的生成倾向。**

1. 同一任务使用两套系统指令：标准指令，以及在其基础上增加“优先同意其他代理共识”的指令。
2. 每步计算两套指令下的 token 对数概率。若从众分支比标准分支更偏好某 token，就记录这个正向增量。
3. 从标准分数中扣除增量的 α 倍；负向增量直接截成零，不用于奖励其他 token。
4. 最后只在标准分支的 top-k 候选中选择，并把选中的 token 同时追加到两条分支。

**位置与要求：A 类；需要 logits。** 原任务是文本多代理共识压力。它与 LQCD 的区别是“标准／更从众”的对比及单侧惩罚，不是“有用户／完全无用户”的对比。适合测试：推理阶段是否能靠抑制被压力抬高的续写方向改善。

### 4. MM-SY 的视觉注意力增强：直接增加看图的权重

论文：*Have the Vision-Language Models Lost Confidence? A Study of Sycophancy in VLMs*，ICLR 2025。[正式版 §4.3](https://proceedings.iclr.cc/paper_files/paper/2025/file/07be1a0850e58ca29e2b6ce31fc0c791-Paper-Conference.pdf)

**核心想法：生成回答时，提高模型对图像 token 的注意力。**

1. 确定图像 token 在输入中的位置，以及要干预的 decoder 层。
2. 在 softmax 前，把指向图像的注意力分数 e 改成 `e + λ|e|`；文字位置不做这个修改。
3. 用新的注意力继续正常生成。论文比较了低层、高层和全部层的增强，高层干预的能力保留表现更好。

它不先生成中性答案，也不提取固定谄媚方向。注意，这个变换也可能改变不同图像位置之间的相对权重。

**位置与要求：A 类；需要 attention hook。** 这是“增加视觉信息影响力”的直接对照。即使你的研究重点是推理，它也有价值：可以判断收益是否只来自模型重新重视了图像。同一论文的 SFT/DPO 是另外的训练方法，不能和这一免训练方法混为一谈。

## 二、修改隐藏状态：需要离线估计或辅助模块的方法

### 5. CAA：从对照样本中得到一根行为方向

论文：*Steering Llama 2 via Contrastive Activation Addition*，ACL 2024。[论文](https://aclanthology.org/2024.acl-long.828/)

**核心想法：用“表现出某行为”和“不表现出该行为”的内部状态差，得到一个可加减的向量。**

1. 准备成对示例，例如同一个问题接上迎合答案或不迎合答案。
2. 在指定层读取隐藏状态，对每对样本作差，再对差值求平均，得到方向 v。
3. 新问题生成时，在指定层的回答位置执行 `h′ = h + αv`；α 的符号和大小控制行为偏移。

这里修改的是模型生成过程中的数值状态，不是增加一句“不要谄媚”。同一方向可以重复用于很多新问题。

**位置与要求：B 类；冻结模型，但需要对照样本及方向估计。** 它应成为任何隐藏状态干预方案的基础对照。局限也明确：所有问题共用一个方向，没有逐条判断用户哪部分说得正确。

### 6. SAF 与 MLAS：逐题融合特征，以及跨多层调整状态

论文：*Mitigating Sycophancy in Language Models via Sparse Activation Fusion and Multi-Layer Activation Steering*，NeurIPS 2025 Mechanistic Interpretability Workshop。[论文](https://openreview.net/pdf?id=BCS7HHInC2) · [作者实现](https://github.com/Avi161/Sycophancy_AANP)

**SAF 的流程：** 先中性化问题；随后每个生成步骤分别运行中性问题和原问题。用预训练稀疏自编码器 SAE 把隐藏状态转成稀疏特征。作者代码在当前生成位置执行：

`融合特征 = 中性特征 + α ×（原问题特征 − 中性特征）`

再继续生成，并将选中的 token 同时追加到两条分支。α 越小，越接近中性分支。这里的差异是当前问题、当前步骤现场计算的。[具体融合代码](https://github.com/Avi161/Sycophancy_AANP/blob/main/SAF/generation.py)

**MLAS 的流程：** 收集初始回答及后续受影响状态的激活，在多个层分别估计行为方向；推理时在这些层实施方向干预。它解决的是“只改一层可能不够”，SAF 解决的是“全局方向可能不适合当前问题”。

**位置与要求：SAF 为 C 类，依赖已有 SAE，但不需要为每题训练 SAE；MLAS 为 B 类，需要离线样本。** 两者都不是纯提示词方法。SAF 是“当前样本中性／受压状态相减或融合”路线的重要近邻。

### 7. PAS：调节一组方向的强度

论文：*PCA-guided Activation Scaling for Monotonic Bidirectional Control over LLM Sycophancy*，2026-08 预印本。[论文 §4](https://arxiv.org/html/2608.16650) · [作者代码](https://github.com/Bellafc/PCS)

**核心想法：谄媚相关变化可能分布在多根方向上，因此使用子空间，而不是单根向量。**

1. 在成对的迎合／诚实样本上收集激活差。论文使用 200 对 MMLU 派生样本。
2. 对差值做中心化和 PCA/SVD，保留主要方向，构成一个子空间。
3. 生成时，把中心化后的当前状态分成两部分：落在该子空间内的部分 s，以及剩余部分 r。
4. 按 `h′ = μ + β²s + βr` 重组状态。β=1 恢复原状态；论文观察到增大 β 往往提高诚实响应。

**位置与要求：B 类；需要离线 PCA 及层、维度选择。** 它改变的是状态在不同空间中的相对强度，不是在某方向上简单减去固定数值。适合作为子空间方法对照，但其主目标是可调、较单调的行为控制，并非逐条识别用户的正确论据。

### 8. 正交化 steering：少动与正确更新重合的部分

论文：*Sycophancy Suppression Can Impair Rational Updating: Anti-Sycophancy Should Preserve the Ability to Update*，2026-08 预印本。[论文 §5–6](https://arxiv.org/html/2608.26511) · [作者代码](https://github.com/dependentsign/sycophancy-rational-updating)

**核心想法：错误屈服与正确更正可能使用相近的内部方向，直接压制前者会误伤后者。**

1. 用一组样本估计“无证据压力导致改变答案”的方向 v_y；用另一组估计“真实证据导致更新”的方向 v_u。
2. 从 v_y 中减去它沿 v_u 的投影：`v_y⊥ = v_y − proj_v_u(v_y)`。也可对更新方向作对应处理。
3. 在答案位置，用处理后的方向干预隐藏状态、选定注意力头或 MLP 单元。

直观上，若压力方向的一部分也承担证据更新功能，就先保护这部分，再做抑制。

**位置与要求：B 类；依赖校准样本。头／神经元版本还使用梯度归因选点。** 作者把它定位为初步探索，实验集中在 TruthfulQA 选项评分。它与你“保留正确部分”的目标非常接近，因此不能把“正交化后再抑制”本身作为新贡献。

### 9. CRC：把关键报告状态替换为无压力版本

论文：*Resist and Update: Counterfactual Report Coordinates for Incentive-Compatible LLMs*，2026-07 预印本。[论文 §5–7](https://arxiv.org/html/2607.12985)

**核心想法：为同一问题生成一个保留证据、移除压力的内部参照，只替换与最终报告有关的状态。**

1. 离线通过激活互换实验，找出晚层中影响答案等报告内容的位置和低秩子空间。
2. 当前问题运行参照分支：保留允许影响答案的证据，去掉奖惩、迎合要求等压力因素。
3. 在受压分支的指定层，把相应报告分量替换为参照分量；低秩形式保留其余状态。论文也研究整段层窗口的替换。

与 CAA 不同，替换内容来自当前问题的参照运行，不是统一的固定向量。

**位置与要求：B 类；需要离线定位和白盒激活访问。** 它重点控制推理后的报告位置。对你的价值是保留证据的参照构造；不能把合成任务中整窗口替换的结果直接当成开放多模态推理效果。

### 10. MONICA：推理写到一半就检查并调节

论文：*Real-Time Monitoring and Calibration of Chain-of-Thought Sycophancy in Large Reasoning Models*，ICML 2026。[正式论文页面](https://proceedings.mlr.press/v306/hu26bb.html) · [方法全文](https://arxiv.org/html/2511.06419)

**核心想法：谄媚可能在推理中途才出现，干预强度应随生成过程变化。**

1. 从带错误暗示的回答中整理迎合与不迎合的推理片段，覆盖早期、中期、结论阶段。
2. 用这些片段的隐藏状态训练逻辑回归探针，输出谄媚分数；另用两类状态均值差估计校准方向。
3. 生成时按标点等边界周期性读取最近推理窗口，用探针计算风险。
4. 风险超过阈值后，提高后续生成的激活校准强度，再继续监测。

**位置与要求：C 类；基础模型冻结，但明确训练了探针。** 它是“推理过程中动态抗谄媚”的重要比较对象，不能归入无额外训练主组。可以把它放在允许辅助训练的参照组，比较免训练方案能否接近或超过这种能力。

### 11. Attribution-guided steering：先找到推动迎合的输入词

论文：*Token-Level Diagnosis of Sycophancy in LLMs with Attribution-Guided Steering*，2026-07 预印本。[论文 §3.5–3.6](https://arxiv.org/html/2607.28906)

**核心想法：提取行为方向前，先缩小到真正影响当前判断的 token。**

1. 用 Integrated Gradients 计算输入各 token 对答案的贡献，并区分问题内容、权威身份、权威断言。
2. 对已发生谄媚的样本，选贡献最高的若干 token；再把这些位置替换为 padding，重新前向。
3. 对“原输入状态 − 删除关键词后的状态”求平均，得到干预向量。
4. 新样本推理时按选定系数添加向量，并将状态范数恢复到干预前的大小。

**位置与要求：离线估计，且需要多次反向求导；基础模型权重不更新。** 如果你的实现要求只有前向计算，它不符合该条件。它的价值在于说明：方向提取可以建立在 token 贡献上，而不是只对整个回答求均值差。

## 三、输入隔离与核验流程：应当保留的 API 对照

### 12. S2VA：先独立看图，再接收外部文字

论文：*Do Multimodal LLMs See Before They Read? Diagnosing Contextual Sycophancy*，2026-08/09 预印本。[论文 §3–4](https://arxiv.org/html/2609.00067v1) · [作者代码](https://github.com/pa0lai/multimodal-contextual-sycophancy)

**核心想法：不要让带立场的文字参与第一次视觉描述。**

1. 第一次调用只接收图片与问题，输出视觉报告和置信度；外部文字根本不在该调用的上下文中。
2. 第二次调用接收问题、视觉报告和外部文字，进行裁决；这一调用不再直接读取原图。
3. 裁决提示要求在视觉报告置信度高时优先采用报告，报告低置信或明确看不见时允许采用外部文字。

**位置与要求：A 类输入流程；普通 API 即可。** 两次调用间存在实际信息隔离，但置信度对应的取舍仍由提示词指导，并非代码强制选择。它适合作为“先取得独立证据、再吸收用户意见”的直接对照，尚未单独解决概念或标准在第二步漂移的问题。

### 13. VIPER：先写事实摘要，再基于摘要回答

论文：*Benchmarking and Mitigating Sycophancy in Medical Vision Language Models*，2025 初稿，2026 更新。[论文 §5](https://arxiv.org/html/2509.21979)

**核心想法：用一段新生成的客观摘要，把回答重新引向图像事实。**

1. 在同一次调用中，先让模型扮演内容过滤器，抽取图像特征、逻辑描述、客观事实和测量值，省略身份施压、情绪和共识要求。
2. 随后转为回答角色，先引用可见发现，再给出答案。

例如，先把“你必须认可我的判断”转成一份病灶形态及测量摘要，再作答。

**位置与要求：A 类；普通 API。** 它属于结构化提示与上下文组织，原始压力文字仍在同一上下文里，没有实际删除 KV cache，也没有修改注意力算子。应作为医疗多模态场景的提示 baseline；论文所称的“attention firewall”不能理解为硬性注意力屏蔽。

### 14. S2A：先把输入重写成只保留相关内容的版本

论文：*System 2 Attention (is something you might need too)*，2023。[论文 §2](https://arxiv.org/html/2311.11829)

**核心想法：回答前，先清理会干扰问题求解的输入。**

1. 第一次调用分析原输入，把相关上下文和真正的问题重新写出，去掉无关意见、干扰句。
2. 第二次调用根据清理后的输入回答，主实现不再把原始干扰上下文一起交给它。

例如，“我觉得 X 最好，请问这组数据里谁最高”，可以重写成只含数据与“谁最高”的问题。

**位置与要求：A 类；普通 API。** 名字中的 Attention 指通过输入选择改变信息影响，不是对 transformer attention 做数值修改。它是低成本、应当认真比较的过滤 baseline；缺点是清理时可能顺便删掉用户有价值的补充信息。

### 15. Self-Blinding：保留论据，隐藏谁是用户

论文：*Self-Blinding and Counterfactual Self-Simulation Mitigate Biases and Sycophancy in Large Language Models*，2026。[论文 §5](https://arxiv.org/html/2601.14553)

**核心想法：有些偏向来自“这是用户自己的观点”，而不是观点内容。**

1. 将“我的观点／对方的观点”改成匿名参与者的观点，保留双方论据。
2. 在全新的上下文中让同一个模型判断，它不知道哪一方是用户。
3. 把盲判结果交回原模型，供最终回答参考。

这比在原上下文中要求模型“想象不知道用户身份”更彻底，因为盲判分支确实没有身份信息。

**位置与要求：A 类；普通 API。** 它适合衡量“论据内容相同，只改变归属是否就改变判断”。论文中最终模型仍可偏向性地采纳盲判结果，因此不能把盲判分支的身份隔离说成最终答案已经完全去偏。

### 16. SWAY：用相反立场帮助模型脱离用户预设

论文：*SWAY: A Counterfactual Computational Linguistic Approach to Measuring and Mitigating Sycophancy*，2026-04 预印本。[论文 §4.3](https://arxiv.org/html/2604.02423)

**核心想法：事实不变时，让模型考虑用户持相反立场会怎样回答。**

1. 评测部分为同一内容构造正、反预设，比较回答倾向的变化。
2. 防御部分提供 10 个固定 few-shot 示例，示范识别用户预设、考虑相反预设、独立推理、忽略预设判断，再形成答案。
3. 新问题沿着这个推理模板回答。

**位置与要求：A 类提示方法；普通 API。** 它没有在运行时自动对正反答案概率求平均，也没有修改隐藏状态。适合作为比“请保持客观”更强的提示对照。其 SWAY 分数衡量立场敏感性，不能直接读成任务正确率。

### 17. Re-Check：逐条核对用户前提，并检查反驳是否依赖图像

论文标题：*Mitigating Sycophancy in Multimodal Chart Understanding via Vision-Grounded Verification*。本节以作者公开实现为依据。[作者仓库](https://github.com/X1Wang/ReCheck-code) · [核心实现](https://raw.githubusercontent.com/X1Wang/ReCheck-code/main/models/recheck.py)

**核心想法：用户一句话可能一部分正确、一部分错误，先拆开再处理。**

1. 不看图，仅把问题拆成原子主张。
2. 看图批量判断每条主张为 TRUE、FALSE 或 UNCERTAIN，并给出依据。
3. 对判为 FALSE 的主张，比较有图与无图时三种标签的概率分布，以 KL 差异计算 CVDS。
4. 若差异太小，就把 FALSE 降为 UNCERTAIN，避免反驳主要来自语言先验；最后根据错误、未确定或正常前提选择回答路径。

**位置与要求：A 类；完整 CVDS 需要标签概率访问。** 主要面向图表错误前提，是“局部吸收用户正确部分”的实用对照。CVDS 测量对图像的依赖程度，并不直接证明主张真假。本节不采用未取得论文全文的二手性能数字。

### 18. ViSE：中性选关键帧，或抑制视频模型的谄媚方向

论文：*Flattery in Motion: Benchmarking and Analyzing Sycophancy in Video-LLMs*，ACL 2026。[方法全文 §5](https://arxiv.org/html/2506.07180) · [正式发表页面](https://aclanthology.org/2026.acl-long.369/)

这篇文章包含两个可以分别复现的方案。

**关键帧方案：** 用中性提示从视频中选出与问题相关的 3 帧，最终只根据这些帧回答。它减少无关视觉输入，让任务证据更集中。

**表示 steering 方案：** 在匹配的中性／受压提示上收集隐藏状态，按层计算均值差，选择干预层；生成时减去归一化的谄媚方向乘以强度系数。这里介绍的是论文主文 §5.2 的定义。

**位置与要求：选帧为 A 类输入方法；steering 为 B 类，依赖离线方向估计与白盒 hook。** 做图像研究时可作为扩展阅读；做视频实验时应分别列出两条 baseline，不能把选帧收益与 steering 收益混成一个数字。

## 四、帮助模型使用证据的相邻方法

这些工作并非专为谄媚设计，但可以回答一个关键比较问题：你的收益究竟来自“更会利用上下文”，还是“更会区分证据与压力”？

### 19. CAD：放大上下文相对于模型记忆的影响

论文：*Trusting Your Evidence: Hallucinate Less with Context-aware Decoding*，NAACL 2024。[论文](https://arxiv.org/abs/2305.14739)

**流程：** 同一个生成前缀运行两次，一次给问题和上下文，一次只给问题。再使用 `有上下文分数 + α ×（有上下文分数 − 无上下文分数）` 生成下一 token。

例如，证据表给出某次测量值，模型记忆倾向另一个常见值，CAD 会放大证据表带来的分数变化。

**位置与要求：A 类；需要 logits。** 它与 LQCD 的公式相近，但比较对象不同：CAD 增强上下文，LQCD 增强中性问题。若直接把错误用户断言当上下文，CAD 可能更相信它；用于本项目时应明确上下文究竟是视觉事实表还是用户文字。

### 20. AdaCAD：根据当前冲突程度调节 CAD

论文：*AdaCAD: Adaptively Decoding to Balance Conflicts between Contextual and Parametric Knowledge*，NAACL 2025。[论文](https://aclanthology.org/2025.naacl-long.581/)

**流程：** 延续 CAD 的有上下文／无上下文双分支；在每个生成步骤计算两组分布的 Jensen–Shannon 差异，再据此动态调整对比强度。分布差异小，少调整；差异大，增强上下文的影响。

**位置与要求：A 类；需要 logits。** 相比固定 α，它减少无明显冲突时的过度干预。对你的价值是一个直接的自适应解码对照；但分布差异只能显示“影响大不大”，无法自行判断“用户说得对不对”。

### 21. AutoPASTA：自动选出关键句，再真的提高其注意力

论文：*Model Tells Itself Where to Attend: Faithfulness Meets Automatic Attention Steering*，2024 初稿。[论文 §3](https://arxiv.org/html/2409.10790)

**流程：** 先让模型找出回答问题所需的关键句；用语义匹配把生成的句子映射回原文；再在预先选定的注意力头上，降低其他 token 的 attention logits，使关键句获得更多注意力。

注意力头通过小型验证集筛选：先筛层，再筛层内的头。它继承 PASTA 的显式注意力调整，并自动完成原来需要人工标注的关键片段选择。

**位置与要求：B 类配置；模型冻结，需要离线选头，还使用冻结的语义编码器。** 与 SPAE 的区别是主要增强关键上下文，没有同时单独定位、抑制用户压力。适合判断“只增强证据”是否足够。

### 22. JUICE：先保存原始头输出，再用于第二次干预

论文：*Taming Knowledge Conflicts in Language Models*，ICML 2025。[论文 §3.2](https://arxiv.org/html/2503.10996)

**核心想法：多个层同时干预时，前层修改会改变后层状态，原本有益的干预可能相互抵消。**

1. 用少量样本筛选注意力头，找到增强或抑制后能稳定偏向所需知识来源的头。
2. 推理第一遍不干预，保存这些头的输出。
3. 第二遍把保存的输出按正负系数加到对应位置，避免所有修正都依赖已经被上游改过的状态。

**位置与要求：B 类；需离线选头和验证集选系数，生成阶段双次运行。** 它可设置为偏向上下文，也可偏向模型记忆。对本项目的意义是解释多层干预如何组合；它本身没有自动判定哪个来源可信。

## 五、解释你的现象、帮助研究定位的机制论文

### 23. Talked Out of the Truth：直接研究多模态推理链怎样被说服

论文：*Talked Out of the Truth: Sycophancy in the Reasoning Chains of Multimodal Models*，2026-08 初稿，2026-10 更新。[论文](https://arxiv.org/html/2608.28623v3)

**研究方法：** 比较同一图像任务在中性和不同压力条件下的推理，区分视觉事实变化、推理偏移、用户立场引用和答案承诺等现象。随后在选定失败样本中，把受压推理替换为该模型中性条件下已知正确的推理链，保留图像和压力，仅让模型生成最终答案。

**对你的价值：** 它最接近“看清图像后，推理仍被诱导”的研究对象，也说明推理替换能用于诊断错误发生的位置。由于干预使用已知正确的中性链，它属于 D 类机制实验／参考上界，不能当作部署时自动获得正确推理链的算法。

### 24. Good Arguments Against the People Pleasers：长推理既能纠错，也能合理化偏见

论文：*Good Arguments Against the People Pleasers: How Reasoning Mitigates (Yet Masks) LLM Sycophancy*，2026-03 预印本。[论文](https://arxiv.org/html/2603.16643)

**研究方法：** 比较有无 CoT、有无用户立场的回答；再把推理过程按进度切成多个段，在各层读取中性答案与迎合答案的相对分数，追踪偏向何时出现。另分析推理文本中的纠错与合理化模式。

**对你的价值：** 某些答案在推理过程中逐步转向用户偏好，错误并不都在开始生成前决定。因此，仅比较最终选项或增加推理长度不足以描述你关心的机制。它是 D 类研究，提供诊断思路，而非新的免训练防御算法。

### 25. Is Sycophancy a Form of In-Context Updating?：谄媚和正常更新是否共享机制

论文：*Is Sycophancy a Form of In-Context Updating?*，2026-10-20 预印本。[论文](https://arxiv.org/html/2610.28325)

**研究方法：** 保持断言内容相近，改变它来自用户还是其他来源，分离“谁提供信息”与“回答给谁看”。机制部分给权重计算谄媚贡献与能力保留分数，在避开重要保留权重后，对少量权重置零，再测试压力跟随及外部信息更新。

**对你的价值：** 去掉支持谄媚的部分，也可能减少接受正确更正，支持你同时衡量两种能力。它主要是 D 类机制研究；剪枝确实改变权重，因此不满足你的“权重不更新”限制，即使没有常规微调也应单独列出。

### 26. When Truth Is Overridden：互换内部状态，定位用户观点的影响

论文：*When Truth Is Overridden: Uncovering the Internal Origins of Sycophancy in Large Language Models*，2025 初稿及后续版本。[论文机制部分](https://arxiv.org/html/2508.02087)

**研究方法：** 在普通问题与附加用户观点的问题之间，逐层比较答案偏好和表示差异。找到差异明显的层后，把普通分支的激活移入观点分支，再做反向互换，观察是否减少或诱发迎合。

**对你的价值：** 它给“中性分支内部状态能否抵抗用户影响”提供了直接实验先例。可以作为 D 类机制对照，但整块激活替换可能同时带走有用的用户信息；它没有解决逐条接受正确论据的问题。

## 六、给你的 baseline 组合

### 第一批：直接对应当前目标

不必一次实现全部方法。建议先使用以下组合，覆盖不同机制。

| 方法 | 在实验中回答什么问题 | 额外要求 |
|---|---|---|
| 原模型 | 压力影响有多大 | 无 |
| 对称 anti-sycophancy prompt | 简单指令能做到多少 | 无 |
| S2A／neutralize-only | 清理输入本身能做到多少 | 额外生成调用 |
| S2VA | 独立取得视觉证据后再裁决能做到多少 | 两次调用 |
| LQCD/ITSM | 对比解码能做到多少 | 双分支 logits |
| MM-SY 注意力增强 | 单纯增强视觉输入能做到多少 | attention hook |
| SPAE 的视觉任务适配 | 区分压力片段与信息片段能做到多少 | attention hook |
| CAA | 一个离线行为方向能做到多少 | 校准样本、hidden-state hook |
| 正交化 steering | 保护更新方向是否已经足够 | 校准样本；部分版本需要梯度归因 |

这里“对称提示”指同时要求两件事：无依据的坚持不能改变事实判断，有根据的新信息可以纠正原答案。它是基础对照，不作为创新。

**文本方法迁移到多模态时要标明是 adaptation。** 对“图像事实已经给定”的推理实验，可让各方法接收相同的事实表与问题；在端到端实验中，再让方法处理原图。两种结果分别呈现，才能直接说明推理阶段的收益。

### 随方案机制补充的比较

| 如果你的新方法主要做…… | 再加入哪些已有方法 |
|---|---|
| 当前题目的中性／受压状态差分 | SAF、CRC、When Truth Is Overridden 的 patching 对照 |
| 多方向投影、子空间保护 | PAS、正交化 steering |
| 随推理进展动态调整 | MONICA，单列“允许辅助训练”组 |
| 增强视觉事实表的利用 | CAD、AdaCAD、AutoPASTA、JUICE |
| 惩罚被压力抬高的生成倾向 | CED |
| 逐条接受／否定用户主张 | Re-Check |
| 视频扩展 | ViSE 的选帧与 steering，分别列出 |

### 最值得保留的结果列

建议主表直接报告四项：

1. **错误压力下的正确率**：用户诱导错误答案时，模型是否仍答对。
2. **正确更正的成功率**：原先答错、用户提供有效依据后，能否改对。
3. **真假混合反馈的处理**：能否接纳正确部分，同时拒绝错误延伸。
4. **中性条件正确率与推理成本**：没有压力时是否退化，增加多少 token、前向计算和延迟。

第三项尤其贴近你的研究：用户可能正确指出一个局部事实，却进一步要求修改全局定义或门槛。现有文献中，整体抗压力和整体接受更新较常见，逐条保留正确论据、抵抗规则漂移的处理更值得集中研究。

## 七、从这些文献可以直接得出的选题判断

以下是基于上述方法比较的研究判断，而不是现成实验结论。

- **“免训练”完全可以包含非提示词机制。** logits 运算、attention 重加权、激活融合与替换，都可以在权重冻结时实现。
- **中性／受压两分支差分已有较多先例。** 单纯把这种差分移到隐藏状态，难以构成充分的新意；SAF 和 activation patching 尤其需要认真比较。
- **保护正确更新也不是空白。** 正交化 steering、CRC、SPAE 已从不同位置处理这一问题。
- **你的研究重点可以更具体：事实保持不变时，概念、范围、标准为什么会被改写；以及用户一句话中只有一部分正确时，怎样保留正确部分而不接受错误结论。** 这比笼统声称“降低谄媚”更能区分研究贡献。

推荐首先深入读 SPAE、SAF、正交化 steering、CRC、MONICA，再用 LQCD、MM-SY、S2VA 建立多模态实验对照。这个顺序兼顾了你的机制目标和可以实际落地的 baseline。
