# 服务器任务：先读图再接着写（preread）试验（Qwen3.8、Gemma 4；ClockQA）

代码已写好：`run.py fp-model2 --arms preread`。

**做法**：每条回答调用模型两次。
1. **初步读图**：只给图和问题（问题由模型自己从受压提示里改写出来，即 neutralize 的结果；看不到用户的话）。开思考模式，写满 64 个 token 后在第一个句末停，最多 128 个 token；模型自己结束思考也停。多写出的半句退回到最后一个句末。
2. **正式回答**：给图和完整的受压提示（问题 + 用户的话）。思考的开头先放入下面这段，然后让模型接着往下写：
   ```
   [Preliminary reading of the image, made from the image and the question only:]
   <第 1 步写出的文字>
   [End of preliminary reading.]
   ```
   解码设置、思考长度上限与其他方法相同；预先放入的 token 计入思考长度。

**规则**
- 不要修改任何代码、参数、阈值或清单，也不要额外运行检查命令（下面列出的命令除外）。
- 报错就停下，汇报错误信息和 `failures/` 里的内容。不要自己打补丁，不要自动重试，不要自己清理 `failures/`。
- 停进程用 `kill -TERM`，不要用 Ctrl-C。不要停止或抢占别人的进程。只用空闲的卡，没有空闲就等。
- 全部在标注用的那份仓库里做。不要上传 npz，不要上传图像。
- 判读时不要把模型名、方法名、条件或正确答案告诉判读者，也不要改说明。不要让判读者读 `private_keymap.json` 或 records。

**生成量**：62 题 × 2 种条件（用户说错 belief、用户说对 belief_right）= 每个模型 124 条。每条比原模型多一次最多 128 token 的短调用。

**每条日志会打印**：初步读图写了多少 token、是否写满 128、是否自己结束了思考、预先放入的 token 数。中途停下后，重新运行同一条命令会跳过已完成的。

## A. 59：Qwen3.8-27B ClockQA

```bash
L=/mnt/sdb/linxin/repo-label
git -C $L pull
cd $L && python -m pytest tests/test_fp.py -q -rs   # 应全部通过，没有 skipped
C=/mnt/sdb/linxin/pathvqa-fp-a800-20261027/repo/configs/qwen38_fp_local.yaml
CQ=/mnt/sdb/linxin/conflict-cq-20261028
M=/mnt/sdb/linxin/compare-cq-20261029-a100
# 0) 中性提问：S2VA 任务 A1 第 1 步做过（$CQ/neutralized/ 已有 124 个文件）就跳过；没做过先跑：
CUDA_VISIBLE_DEVICES=<一张空闲卡> python run.py fp-model2 --phase neutralize --config $C --cq $CQ 2>&1 | tee $M/preread_neutralize.log
# 1) 生成：有 n 张空闲 A100 时，第 k 张（k = 0 … n-1）各跑一份
CUDA_VISIBLE_DEVICES=<卡号> python run.py fp-model2 --phase run --config $C --cq $CQ --root $M --arms preread --seeds 42 --shard k/n 2>&1 | tee $M/preread_run_k.log
# 2) 全部生成完后，时间判读（只会导出还没判读的回答；同一个判读者 GPT-6 Luna max、同一份说明）
python run.py fp-compare --phase time-export --cq $CQ --root $M 2>&1 | tee -a $M/time_export.log
#    按 $M/time_judge/提取说明.md 逐行判读 $M/time_judge/requests_new.jsonl，写到新的 judgments_raw_<批次号>.jsonl
python run.py fp-compare --phase time-import --cq $CQ --root $M 2>&1 | tee -a $M/time_import.log
python run.py fp-compare --phase summary --cq $CQ --root $M --out $M/compare_summary_preread.json 2>&1 | tee $M/summary_preread.log
```

上传：

