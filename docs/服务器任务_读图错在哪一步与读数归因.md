# 服务器任务：被带偏时读图错在哪一步（转写），以及写下读数的那一位数字被谁推动（归因）——Qwen3.8、Gemma 4 ClockQA

两件事可以同时做。都**不生成新回答**，用的是已有的原模型回答：每题三条，中性 / 用户说错 / 用户说对，种子 42。

1. **转写**：判读子 agent（GPT-6 Luna max）只读模型的思考和回答，转写模型自己写下的第一次读数和最终读数：两根针各指向哪个刻度、它把哪根叫时针、说出的时间。转写时不看图、不给正确答案、不告诉条件。之后由代码判定每条读数错在哪一步：位置 / 身份 / 计数。
2. **归因**：GPU 只读回放。在模型自己写出读数的那一位数字上，把各注意力层的输出按来源（图像 / 用户那句话 / 提示其他 / 自己前文）拆开，看谁把这一位推向正确数字、谁推向用户的数字。程序每一步都会自检，不通过就报错停下。

**规则**
- 不要修改任何代码、参数、阈值或清单，也不要额外运行检查命令（下面列出的命令除外）。
- 报错就停下，汇报错误信息和 `failures/` 里的内容。不要自己打补丁，不要自动重试，不要自己清理 `failures/`。
- 停进程用 `kill -TERM`，不要用 Ctrl-C。不要停止或抢占别人的进程。只用空闲的卡，没有空闲就等。
- 判读时不要把模型名、条件或正确答案告诉判读者，也不要改说明。不要让判读者读 `private_keymap.json` 或 records。
- 不要上传 npz。

## A. 59：Qwen3.8-27B

```bash
L=/mnt/sdb/linxin/repo-label

cd $L && python -m pytest tests/test_fp.py -q -rs   # 应全部通过，没有 skipped

CQ=/mnt/sdb/linxin/conflict-cq-20261028
M=/mnt/sdb/linxin/compare-cq-20261029-a100
T=/mnt/sdb/linxin/qwen38-cq-stages-20261102      # 新目录
mkdir -p $T
```

### A1. 转写（186 条，判读子 agent）

```bash
python run.py fp-sources --phase stage-export --cq $CQ --root $T --label "Qwen3.8-27B · ClockQA" 2>&1 | tee $T/stage_export.log
# 把 $T/stage_judge/instructions.md 和 queue.json 交给判读子 agent（GPT-6 Luna max），标签写到 $T/stage_judge/labels/<key>.json
python run.py fp-sources --phase stage-summary --cq $CQ --root $T --judgments $M/time_judge/judgments.json --label "Qwen3.8-27B · ClockQA" 2>&1 | tee $T/stage_summary.log
```

程序会校验每个标签：引文必须是原文里连续的一段，刻度在 0–12 之间。不通过会报错停下。

### A2. 归因（GPU，186 条，只读回放）

```bash
# 有 n 张空闲 A100 时，第 k 张（k = 0 … n-1）各跑一份：
CUDA_VISIBLE_DEVICES=<卡号> python run.py fp-sources --phase attrib --config $C --cq $CQ --root $T --shard k/n 2>&1 | tee $T/attrib_k.log
# 全部跑完后（CPU）：
python run.py fp-sources --phase attrib-summary --cq $CQ --root $T --judgments $M/time_judge/judgments.json --label "Qwen3.8-27B · ClockQA" 2>&1 | tee $T/attrib_summary.log
```

- 每条会打印：找到几个目标位置；第一个目标上，图像、用户那句话、自己前文各贡献多少；拆分自检的最大相对差。
- 两项自检任一不通过，程序都会报错停下：
  - 各来源之和与每层实际输出相差超过 2%；
  - 重算出的 logit 与模型实际输出相差超过 5%。
