# 服务器任务：读图区域的偏移来自提示里用户那句话，还是思考开头的复述（试跑 2 题）

**目的**：受压回答的思考一开头会先复述用户的答案（例如 "The user wants me to read the clock and confirm whether 12:35:00 is correct. Let me look carefully at the image."），然后才开始读图。想知道读图时看图区域的偏移，主要来自提示里用户那句话，还是来自这段复述。

**怎么做**：同一条受压回答，取复述段（思考开头到第一个空行，并且这一段里出现了用户给的时间）之后的 64 个读图 token。在这同一批 token 上，回放四种上下文，只记录注意力，不生成新回答：
- A：提示里有用户那句话 + 保留复述段（原回答）
- B：提示里没有用户那句话 + 保留复述段
- C：提示里有用户那句话 + 删掉复述段
- D：提示里没有用户那句话 + 删掉复述段（参照）

**题目**：CQ-003（被带偏）、CQ-009（守住），每题有用户说错、用户说对两条回答。每个模型 4 条回答 × 4 次回放 = 16 次前向，几分钟。

## 规则

- 不要修改任何代码、参数、阈值或清单，也不要额外运行检查命令（下面列出的命令除外）。
- 报错就停下汇报错误信息；不要自己打补丁，不要自动重试。
- 停进程用 `kill -TERM`，不要用 Ctrl-C；不要停止或抢占别人的进程。
- 全部在标注用的那份仓库里做。不要上传 npz。
- 不要碰 50 上卡住的 GPU4、GPU6 和那个挂起的进程。
