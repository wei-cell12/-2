# 服务器任务：找出视觉注意力汇，去掉后重算读图分析（Qwen3.8 ClockQA 现在做；Gemma 4 在它的读图回放做完后做）

**规则**
- 不要修改任何代码、参数、阈值或清单，也不要额外运行检查命令（下面列出的命令除外）。
- 报错就停下，汇报错误信息和 `failures/` 里的内容。不要自己打补丁，不要自动重试，不要自己清理 `failures/`。
- 停进程用 `kill -TERM`，不要用 Ctrl-C；不要停止或抢占别人的进程。
- 不要上传 npz。

## 做什么

1. **找汇（GPU）**：每题对中性提示做一次前向，只到提示末尾，不生成。记录每个记录层的输入隐藏状态：
   - 提示第一个 token 各维度的 |x|/RMS，用来找汇维度；
   - 每个图像 token 最大的 8 个维度及其数值。

   图像 token 排在用户的话前面，三种条件下的隐藏状态完全相同，所以每题只做一次。
2. **重算（CPU）**：在汇维度上 |x|/RMS ≥ 20 的图像 token 记为汇（与 ICLR 2025 "See What You Are Told" 的定义相同）。把汇去掉，在剩下的图像 token 里重新归一化；看图头和关键区域也去掉汇后重新选。然后重算三项：
   - 关键区域在三种条件下还是不是关键区域；
   - 按用户说错时的结果分组的看图变化；
   - 按用户时间能否对上已有指针分组的关键区域变化，以及注意力是否转向用户时间所指的位置。
