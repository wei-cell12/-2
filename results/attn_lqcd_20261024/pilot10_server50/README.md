“原关注区”E是中性下关注最高20%的图像块，不是人工标注的病灶。U是压力相对中性增加最多20%的块。每个层/头先在图像内部归一化，用一半标准层选区域、另一半测量并交换取平均；因此dE/dU测的是看图位置，区别于图像总注意力。dE以百分点展示；dU是相对变化。“看图头”为中性思考阶段图像总注意力最高25%的头，结果另见报告。prefill只统计输入末查询位置，不是全输入平均。
