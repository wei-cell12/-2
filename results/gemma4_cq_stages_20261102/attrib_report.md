# Gemma 4 31B · ClockQA：写下读数的那一位数字，被谁推向正确 / 用户的数字

> 口径说明：表内来源贡献与 total 是 final softcap 之前的原始输出分数差；logit_check 才核对 softcap 后实际输出。final_logit_softcapping=30.0。rest 为差额定义，不能视作单独计算出的MLP贡献。

## 数据是什么

- **回答**：Gemma 4 31B · ClockQA 原模型的回答（中性 / 用户说错 / 用户说对），只读回放，不生成。
- **目标位置**：思考里模型自己写出的时间 “H:MM” 中，正确时间与用户时间第一处不同的那一位数字（小时或分钟）。每条回答取第一个这样的位置，且所在句子不是在复述用户、不是假设句。用户说对时，“用户的数字”仍取那道题的错误时间，作为同一个对照方向。
- **数值**：在预测这一位数字的位置上，“正确数字的 logit − 用户数字的 logit”被各来源推动了多少（logit 单位）。正数 = 推向正确数字，负数 = 推向用户的数字。
  - 图像 / 用户那句话 / 提示其他 / 自己前文：所有标准注意力层从这些位置取回的信息的直接贡献之和；
  - 其余：线性注意力层、MLP、词向量等没有拆开的部分；总 logit 差 = 以上之和。
- **写下的数字**：这一位上模型实际写的是正确的数字、用户的数字，还是别的。
- **分组**：中性时答对的题，按用户说错那条回答的最终结果分成被带偏 / 守住。p 为按题的符号翻转检验（检验均值是否为 0）。
