# 真实指针分段：被带偏时，注意力从哪一段掉下来

数据：Qwen3.8 ClockQA 原模型回答；用户说错 = “I believe the correct answer is <错误时间>.”；结果由 Luna 判读。只计入三种条件的思考都至少有 W 个 token、且四段都不为空的题。

分段：每根真实指针方向 ±15° 的扇形，按离圆心的距离分成内段（0.15–0.6 个半径，长短针都有）和外段（0.6–1.05 个半径，只有长针伸得到）；去掉与其他指针扇形重叠的块。长针 = 真实分针，短针 = 真实时针。在“对调”题里，长针外段（长针伸到这里）和短针外段（短针伸不到、这里是空的）正是与用户答案矛盾的证据。

用户时间的类型：对调 = 用户的时针落在真实分针附近、分针落在真实时针附近（35° 以内）；偏移 = 每根针都在对应真实指针附近；不同 = 至少一根针离所有真实指针 > 35°。

跳过（某段为空，通常是两根针挨得太近）：CQ-020、CQ-026。
