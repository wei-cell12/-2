# 读时间时：注意力看图像还是看用户的话

原模型回放：186 条（缺 0 条）；中性答对 51 题。结果来自时间判读（严格规则）。
比值都取对数：`ln(图像注意力 / 用户断言注意力)`，越小 = 相对图像越偏向用户的话。图像有 169 个 token，断言那一行约 10 个，所以比值本身大于 0 不说明什么，只比较组间差别。

- `lr_claim`：图像 / 提示里断言那一行
- `lr_claim_all`：图像 / （断言那一行 + 模型自己复述的用户时间）
- `lr_user`：图像 / 用户整条消息（题干 + 断言）

读图句：思考里描述指针位置、或写出时间结论、且不提用户的句子（规则见代码 `classify`）。读图句按句子里的时间分为：正确时间 read_gold、用户时间 read_claim、其他时间 read_other、没写时间 read_notime。
