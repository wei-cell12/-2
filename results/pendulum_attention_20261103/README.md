## 题目数量和实验方法

三款模型：Qwen3.8-27B、Gemma4-31B-it、Qwen3.6-35B-A3B MoE。基线生成使用同一批200题：易混淆视角、视觉谜题、复用图像、自拍图像各50题；每题中性、用户说错、用户说对，各模型600份，合计1800份。200题共84张不同原图。

注意力仅覆盖复用图像与自拍图像各50题，合计100题、23张不同原图；每模型300条回放，共900条。把已有回复原样喂回、被动记录原注意力函数，未重新生成。本批未做注意力恢复干预。完整收集定义与记录维度见[方法说明](methods/attention_collection.md)。

- 匹配思考前64/128/256/512个token；三条件长度都足够且图像全部可见才进入该窗口，不填充。每个窗口独立保存入组ID。
- 各层类按三条件平均图像注意力选前25%看图头：Qwen96/384、MoE40/160、Gemma全局80/320与滑动400/1600。固定96头另作敏感性，不将其混成MoE主分析。
- E是每头中性完整思考的前20%高关注图像块；报告图像总注意力与图像内部E份额，两者分母不同。E是模型自定参照区域。
- JSD先逐头计算再平均，单位nats；同时报告原始JSD和减去条件内部交替8-token组噪声后的差值，保留负数。Gemma全局层、滑动窗口层分别报告。
- 守住/变错/未解按同一模型的中性答对题定义，另给三模型共同中性答对交集。置信区间按原图聚类。

## 标注与复核

复用同一个GPT-6 Luna(max)。新增两模型先封存1200份盲化答案抽取，再揭示参照进行语义匹配、解释审核和主张采纳判读；历史Qwen600份保留。原标注、更正、指令与封存信息见annotation_audit/。同一判读者见过本数据集历史内容，报告未将它描述为全新独立盲审。

答案语义匹配与解释联合正确分开列示；原文没有解释不等于没有作答。42题参考争议并集仅用于另列敏感性分析，未改原金标。

发布时重新逐条核对1800份导出与最终标注的来源SHA、图像SHA和连续引文，独立重建全部条件计数及中性→用户说错的转移表；900份数组元数据全部与对应原回复SHA一致；12张PNG可正常解码。原报告已有16项文件SHA也全部匹配。
