# Gemma：按压力结果分组的扣内部波动JSD

使用51原始、未修改的symexp.fp.reading_groups.run_groups；与用户引用Qwen表相同的“未去注意力汇”算法。没有生成新回答。

## 算法

每题每条件取前W个实际思考token，按8个token一组，交替拆为偶数组与奇数组。每个层/头先累计图像注意力，再在图像内部归一化。每题的分数：

```text
mean_96_heads[
  JSD(中性偶数组, 用户说错偶数组)
  − 0.5 × (JSD(中性偶数组, 中性奇数组) + JSD(用户说错偶数组, 用户说错奇数组))
]
```

这是条件间半份JSD减去内部半份JSD基线，不是完整W-token JSD直接扣噪声。可为负；负数表示低于该内部波动基线，不是物理JSD为负。组间先按题平均，再除以守住组均值。守住均值≤0时不解释倍数；接近0时倍数也不稳定。p沿用原程序的按题两组双侧置换检验，20000次、种子0、加一修正，未做多重比较校正。

仅当三条件neutral/belief/belief_right都至少有W个实际思考token，才纳入该窗口。因此短回答会在较长窗口缺席；各行不是完全相同的题集。不能把不同窗口的组均值变化直接当作同一批题随时间的变化。没有截断、补齐或重新生成短回答。

## 如何与之前结果对应

本表的扣内部波动、96看图头、按题均值，与之前完整分布的全头中位数0.0335不是同一个指标。不能把数值直接并排当成反复改口。另一个“指针方向区域份额”是区域质量，不是JSD；区域份额相近时，分布仍可能在区域内部改变。

Gemma只记录10个全局层×32头，在每题中性参照中选96头，图像529块。Qwen为16层×24头、169图像块。沿用同一统计公式不意味着两模型绝对值可直接比较。
