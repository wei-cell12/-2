# 波谷的行为含义：已完成的直接验证与次级谷实例

本报告使用已有600条熵轨迹、615处深谷的既有语义审核、Qwen ClockQA已保存的逐token注意力。没有重新生成回答或使用GPU。新一轮深浅谷+普通位置的701条盲化扩展判读正在由同一Luna(max)接续，完整完成后报告见同目录REPORT.md；本文件保留为当时已完成证据。

## 明确的用途：抓住用户信息重新介入推理的时点

深负熵差可用于定位“模型正在重新引入、比较、核对用户断言，或者决定如何回应用户”的时机。适合在这个时机触发独立图像事实核查；核查子Agent只接收图像和原问题，再由主Agent比较证据与用户主张。

负差的精确含义是：在同一个已有输出前缀下，有用户信息的分支比没有用户信息的分支更确定。它给出的主要是“下一步依赖用户信息”的信号。检测流程分两级：先由数值信号定位，再读当前动作决定设问。

## 其他局部谷实际在做什么

旧615处深谷里，360处是各轨迹最深的一处，另有255处是第二、第三及后续的深谷，覆盖162条轨迹。这255处中，133处的前文有模型明确疑惑；91处随后复述或评价用户主张；59处局部呈现“视觉推断/观察 → 复述/核对用户 → 再看图/推断”的顺序。这些是位置计数，不是独立题数。以下均为后面255处的例子。深谷阈值ΔH≤−1 nats；token编号从输出第1个token开始。

这些位置可分成不同触发用途：

- 重新引用用户主张：提示“用户的信息现在重新进入决策”，核查主张来源。
- 比较/核对主张：把“图上到底是什么”交给独立子Agent，再与用户断言对照。
- 多个视觉候选之间抓关键证据：对子Agent提出具体设问，如“中央结构是哪一类？出血位于哪里？”，避免泛泛重新思考。
- 重新评估指针/区域：直接触发局部图像复核。
- 确认或纠正用户、组织答复：作为答案承诺检查点，核对拟答是否仍由图像证据支持。

255处按旧版互斥主标签分别为：用户主张复述85、用户主张评价71、任务/答复组织89、直接看图3、视觉推断4、其他1、未解2。这里“答复组织”中包含“Verify user”“Correct user politely”等用户相关标题和计划，不能把它当作“与用户无关”。扩展判读将行为对象与标题/计划分开标注。

规则：同一连续负差段里，第一次ΔH≤−1就触发一次。没有使用未来token、谷底排名、生成文本关键词或注意力做触发。

## 两支各自的熵说明它为什么出现

全部615深谷，受压分支平均熵0.364 nats，去掉用户信息但保持相同前缀的分支平均2.008 nats。与各自前8步相比，受压支平均变化+0.023，去用户支平均变化+1.512 nats。主要现象是：这些位置没有原用户信息时，下一步变得难预测；有用户信息时下一步仍比较确定。

因此可以把深谷作为“用户信息带来的确定性增益点”。语义上它可能落在复述、核对、取舍或回应计划，子Agent设问随具体动作而定。对于用户想找的“犹豫后回去看用户”的情况，使用“前文尚有两个视觉候选/明确疑问 → 深负差触发 → 重新引入用户主张”的三段组合。Gemma CQ-016 token1301就是现有实例：前文秒针候选28或29，接着重新读用户4:04:28，再逐项比较。
