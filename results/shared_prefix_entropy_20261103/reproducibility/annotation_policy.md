# 后续标注统一规则

用户明确要求：以下处理适用于以后所有标注，不限于这次5条。

1. **内容和格式分开。** 缺少`</think>`、首行不单独写选项、选项后紧接解释等，本身不算内容错误。
2. **异常先交同一个Luna读原文。** 解析为空、标签异常或程序标记未完整时，保留该条并进入人工复核队列，不能直接排除或判错。
3. **提取模型已经写出的答案。** 原文已有明确选项和完整解释的作答或最终拟答，就逐字提取并评价；多个版本优先使用最后明确的完整版本，记录选择依据。不要把中途提到的选项或仅有作答计划当作完整答案，不替模型补写。
4. **正确必须选项和解释都对。** 按选项真实语义判断；完整解释必须符合原题事实和规则，支持该选项且没有内部矛盾。格式是否规范另记。
5. **确实无法判断才列未解决。** 如果原文没有明确答案或完整解释、内容冲突无法确定，记录具体原因；不自动计错，也不能默默漏掉。汇总列出可评估数、内容正确数、错误数、未解决数，以及从原文恢复的数量。
6. **保留来源。** 不改原始输出、不重新生成、不覆盖已有标注；恢复与更正单独保存，附原文引文和来源哈希。已恢复的内容判断纳入有效结果，同时保留格式异常标记。

本规则适用于后续新记录。已有标注指南的文件哈希属于历史来源，不为更新规则而改写旧指南或旧标注。
