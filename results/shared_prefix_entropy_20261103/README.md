## 算的是什么

固定已有受压输出前缀y[:k]，比较pU(.|图像,问题,用户话语,y[:k])与p0(.|图像,问题,y[:k])的完整词表原始logits熵。两分支都喂实际受压前缀，中性分支不喂自己的预测。ΔH=HU−H0，单位nats；CSV的第k+1行是生成该token之前的预测。

负差说明该位置用户信息带来了额外的下一步确定性，适合定位用户信息重新介入判断的核查窗口。局部负差段是数值事件，不与独立语义事件/独立题目划等号。

## 这次确认的具体结果

排除每条最大谷后，仍有255处次级深谷；旧轮逐段判读中133处前文有明确疑惑/候选未决，91处接着重新引用或评价用户，59处呈现读图→核对用户→再读图。类别可重叠。

Qwen ClockQA50题100条轨迹与既有注意力逐token完全匹配。76处次级深谷对原输入用户断言及附加请求的注意力平均跳升+3.15个百分点，匹配普通位置-1.58个百分点；配对差+4.73个百分点，原图聚类95%区间+3.15～+6.25。使用16标准层全部384头，不限于96个预选头。

在线可实现规则：每个连续负差段第一次ΔH≤−1提示一次，不等待事后最低点。167次提示覆盖91条轨迹，用户输入注意力平均跳升+4.18个百分点；按原图等权，61.6%同时出现≥2个百分点跳升，普通位置为10.0%。该比例的目标是明确的注意力行为，不是最终答错率。

## 模型、环境和保存范围

Qwen在59跑四个worker，GPU0～3；Gemma在50跑三个双卡worker，GPU0/1、2/3、4/5，每卡权重上限34GiB、device_map auto。计算及保存后进程全部退出，未建立常驻模型或占卡进程。回放环境torch2.11.0+cu130、transformers5.14.1。历史Gemma在51生成时transformers5.20.2，此版本差异保留，不能将本次回放描述为与原生成环境逐版本完全相同。
