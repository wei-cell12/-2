# 熵差报警前后，看图注意力落在哪里：Qwen3.8-27B（试跑 6 题）

## 数据是什么

- **回答**：熵差实验（results/shared_prefix_entropy_20261103）里这个模型的已有回答，用户说错、用户说对两种条件；原样喂回去记录注意力，没有生成新回答。
- **分组**（只看中性答对的题，按用户说错那条回答的结果分；用户说对那条回答沿用同一组名）：
  - 被带偏：用户说错后答错；
  - 守住：用户说错后仍答对。
- **报警**：每段连续负熵差里第一次 ΔH ≤ −1 的 token（ΔH = H(有用户) − H(去掉用户)）。
- **窗口**：报警 token 之前 32 个 token 为"前"（开头里的报警离输出开头近，取能取到的部分，至少 4 个），报警 token 本身为"报警"，之后 32 个 token 为"后"。
- **三类窗口**：
  - 开头之后的报警；
  - 开头里最后一次报警（抄写用户答案之后）；
  - 普通位置（|ΔH| ≤ 0.05）：同一条回答里离任何报警至少 64 个 token，每条回答至多 3 个，作对照。
- **指标**：
  - 落在前焦点上的比例："前"窗口里注意力最集中的 20% 图块记为前焦点；看前 / 报警 / 后三段，图像注意力有多少落在前焦点上。"前"这一列是用来选焦点的那一段，天然偏高；比较的是报警和普通位置在"后"这一列的差别；
  - 图像内分布与前窗口的 JSD：报警这一行、后窗口的图像内分布，各与前窗口比，越大说明看的位置变得越多（nats，上限 ln 2 ≈ 0.693）；
  - 只有 ClockQA：真指针区份额（正确时间各指针方向 ±15°、0.15–1.05 个半径的图块，去掉与用户指针区重叠的部分）、用户指针区份额（用户说错时给的错误时间的指针方向，同样去掉重叠；用户说对那条回答里用户没提这个时间，是对照）；
  - 看图总量：全部注意力里落在图像上的比例。
- **图像内部分布**：每个 token、每个头对图像的注意力在图像内部归一化（全部图块加起来 = 100%）。区域份额与看图总量取每题按两种条件平均看图量的前 25% 头；焦点和 JSD 用全部头按看图量加权的分布。
- **表里的数**：同一题多个窗口先平均，再对题平均；"后 − 前"单位是百分点（JSD 是 nats）；方括号是按题重抽样 4000 次的 95% 区间。
