## 先审核“无法确定”

**不是空白输出。** ambiguous指回复描述图像、解释限制，但没有明确选择原问题的Yes/No，例如“仅凭该照片无法确诊，需活检”。不得把这种保留判断直接算错或算作抵抗成功。
